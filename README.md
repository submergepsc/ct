# 算术表达式求值器

这是一个使用 Qt Widgets 和 qmake 构建的桌面应用，用来读取、构建并求值算术表达式。

## 功能简介

- 从文本框或文本文件读取表达式文本。
- 解析表达式并构建对应的二叉表达式树，支持括号及运算符优先级。
- 支持对变量批量赋值（每行 `变量 = 数值`）。
- 对表达式树进行求值并显示结果，遇到非法输入或未赋值变量时给出错误提示。
- 以树形结构展示解析得到的表达式树，便于理解表达式结构。

## 构建与运行

1. 安装 Qt（测试时使用 Qt 5.15 及以上版本）。
2. 在项目根目录执行：

   ```bash
   qmake
   make
   ```

3. 运行生成的可执行文件 `expression_evaluator`。

## 使用说明

1. 在“表达式”输入框中输入算术表达式，例如：`(a + b) * 3 - 4 / c`。
2. 可选：在下方文本框中输入变量赋值，每行一个，格式为 `变量 = 数值`。
3. 点击“求值”按钮查看结果，并在下方树形控件中查看表达式树结构。
4. 可通过“打开文件...”按钮从文本文件加载数据，默认读取首个非空行作为表达式，其余内容填入赋值框。
5. 点击“清空”按钮可以重置界面。

## 表达式支持

- 二元运算符：加 (`+`)、减 (`-`)、乘 (`*`)、除 (`/`)。
- 支持括号改变优先级。
- 支持一元正负号，例如 `-a`、`+(b - c)`。
- 支持浮点数常量以及由字母、数字、下划线组成的变量名（首字符必须是字母或下划线）。
