# 算术表达式求值器

这是一个使用 Qt Widgets 和 qmake 构建的桌面应用，用来读取、构建并求值算术表达式。程序将输入的中缀算术表达式解析为二叉表达式树（Binary Expression Tree），随后支持变量批量赋值并计算数值结果。

## 功能简介

- 从文本框或文本文件读取表达式文本。
- 解析表达式并构建对应的二叉表达式树，支持括号及运算符优先级。
- 支持对变量批量赋值（每行 `变量 = 数值`）。
- 对表达式树进行求值并显示结果，遇到非法输入或未赋值变量时给出错误提示。
- 以树形结构展示解析得到的表达式树，便于理解表达式结构。
- 具备基本的异常输入防护：非法字符、缺少括号、未赋值变量、除零等会被检测并返回友好提示。

## 与课题要求的对应关系

> 题目摘要：实现对以二叉表达式树表示的算术表达式 `Expression` 进行读取、构建、赋值与求值。

| 课题操作 | 对应实现 | 核心流程 |
| --- | --- | --- |
| `ReadExpr(E)` | `ExpressionEvaluator::ReadInput` | 将字符串表达式词法拆分为 Token，使用递归下降算法按“项/因子/一元正负”层级生成二叉表达式树，校验括号与结束符。 |
| `WriteExpr(E)` | `MainWindow::renderTree`（通过 `ExpressionEvaluator::root`） | 构建 `QStandardItemModel` 并绑定到 `QTreeView`，把树形结构可视化输出。 |
| `Assign(V, c)` | `ExpressionEvaluator::Assign` | 按行解析 `变量 = 数值`，校验标识符合法性和数值可解析性，将赋值结果存入 `QMap<QString, double>`。 |
| `Value(E)` | `ExpressionEvaluator::Evaluate` | 自根递归求值，变量按赋值表替换；处理中除零、未赋值变量、未知运算符等异常并回传错误信息。 |

支持的输入范围：

- 变量名：字母/下划线开头，后续可含字母、数字、下划线。
- 常量：浮点数或整数，支持小数点。
- 二元运算符：`+`、`-`、`*`、`/`；支持括号；支持一元正负号（如 `-a`、`+(b-c)`）。

## 构建与运行

1. 安装 Qt（测试时使用 Qt 5.15 及以上版本）。
2. 在项目根目录执行：

   ```bash
   qmake
   make
   ```

3. 运行生成的可执行文件 `expression_evaluator`。

## 使用说明

1. 在“表达式”输入框中输入算术表达式，例如：`(a + b) * 3 - 4 / c`。
2. 可选：在“变量赋值”文本框中输入变量赋值，每行一个，格式为 `变量 = 数值`（如 `a = 2.5`）。
3. 点击“求值”：
   - 解析并构建表达式树（`ReadExpr`）。
   - 将树以层级结构显示在界面（`WriteExpr`）。
   - 根据赋值表递归求值并显示结果（`Assign` + `Value`）。
4. 可通过“打开文件...”按钮从文本文件加载：首个非空行作为表达式，其余行填入赋值框。
5. 点击“清空”按钮可快速清除表达式、赋值与结果。

### 快速验证用例

可直接在界面使用以下表达式检查解析与求值逻辑（赋值可自行补充或留空）：

- `0`、`a`、`-91`、`a+b*c`、`+-5^a*2*8x`、`+++3^3*2^a/2x6`（示例遵循题目要求的“不保证输入完全正确，需要捕获异常”思路）。
- 每输入一条表达式后，可尝试重复赋值并求值，验证变量更新是否生效。
- 重点观察括号、运算符优先级、一元正负号、非法字符/缺括号/除零/未赋值变量等异常提示是否准确。

## 表达式支持

- 二元运算符：加 (`+`)、减 (`-`)、乘 (`*`)、除 (`/`)。
- 支持括号改变优先级。
- 支持一元正负号，例如 `-a`、`+(b - c)`。
- 支持浮点数常量以及由字母、数字、下划线组成的变量名（首字符必须是字母或下划线）。

## 实现细节速览

- **词法分析**：按空白分隔，识别数字、标识符、运算符与括号，生成 `Token` 序列。
- **递归下降语法**：`Expression -> Term ((+|-) Term)*`，`Term -> Factor ((*|/) Factor)*`，`Factor -> Number | Identifier | (Expression) | (+|-) Factor`，自然实现运算符优先级与一元正负。
- **表达式树**：每个运算符节点的左右子树分别存放运算对象，便于后续可视化与求值。
- **求值**：从根递归计算，变量在 `Assign` 阶段缓存于 `QMap`，除零或缺值立即返回错误。
- **错误提示**：缺括号、意外结束、非法字符、无效变量名、不可解析数字、除零、未赋值变量等都会生成明确的提示信息，便于调试与课程验收。
