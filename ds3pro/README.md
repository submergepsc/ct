# 教学计划编排问题（Qt 实现）

使用 Qt (C++17) 构建的图形界面程序，解决截图中的教学计划编排问题：给定 12 门课程、先修关系、学分与每学期学分上限，生成 6 学期的排课方案。UI 通过 `schedulerwidget.ui` 设计，源文件与本 README 同级，无 `src` 子目录。

## 构建与运行

1. 确保安装 Qt 开发环境（Qt 5.15+ 测试通过）。
2. 在项目根目录执行：

   ```bash
   qmake
   make -j
   ./ds3pro    # 生成的可执行文件名与项目同名
   ```

程序使用题目给出的 12 门课程与学分上限（默认 6 学期、每学期 10 学分），可在界面上调整参数后重新生成方案。界面按钮“生成排课”将输出学期明细或错误信息。

## 输出示例

```
学期 1（总学分 2）：c1 程序设计基础(2)
学期 2（总学分 10）：c3 数据结构(4)、c2 高等数学(3)、c4 汇编语言(3)
学期 3（总学分 8）：c6 计算机原理(4)、c5 高级语言程序设计(2)、c11 数值计算(2)
学期 4（总学分 9）：c10 计算机网络(5)、c8 操作系统(4)
学期 5（总学分 6）：c7 编译原理(3)、c12 数值分析(3)
学期 6（总学分 7）：c9 软件工程(7)
排课成功：12 门课程全部在 6 个学期内完成，总学分 42。
```

## 说明

- 课程数据与先修关系直接写入 `main.cpp` 的 `sampleCourses()`，方便按题目要求运行。
- 排课算法使用拓扑排序思路：优先安排依赖多、学分高的课程，并受每学期学分上限约束；若出现环路、未知先修或学分上限太小，会抛出错误并打印提示。
