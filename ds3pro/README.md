# 教学计划编排问题（Qt 实现）

使用 Qt (C++17) 构建的图形界面程序，解决截图中的教学计划编排问题：给定课程列表、先修关系、学分与每学期学分上限，生成若干学期的排课方案。UI 通过 `mainwindow.ui` 设计，源文件与本 README 同级，无 `src` 子目录。

## 构建与运行

1. 确保安装 Qt 开发环境（Qt 5.15+ 测试通过）。
2. 在项目根目录执行：

   ```bash
   qmake
   make -j
   ./ds3pro    # 生成的可执行文件名与项目同名
   ```

程序默认加载题目给出的 12 门课程（学期数 6、学分上限 10），可在界面上调整参数和“排课策略”（负载均衡/前置集中）后重新生成方案。界面按钮“生成排课”将输出学期明细或错误信息。

## 功能与实现说明

### 输入与约束
- 支持设置学期总数与每学期学分上限；学期数必须在 1~12 之间、学分上限大于 0。
- 课程列表（包含课程号、名称、学分、直接先修课程）可在界面文本框直接输入，也可从文件读取并显示；默认在程序目录下创建 `courses.txt`，内容即截图中的 12 门课。
- 校验规则：
  - 课程总数不能超过 100，课程总学分不能超过 100，单门课程学分必须大于 0。
  - 课程编号必须是固定 3 位的字母/数字串，课程编号和名称不可重复，先修课程必须存在于课程列表中。
  - 先修关系若存在环路则立即报错。

### 排课策略
- **负载均衡**：在满足先修条件下，将可安排课程按“学分小→依赖多→编号”排序，并尝试将各学期学分压向均值，避免单学期过重。
- **前置集中**：在满足先修条件下，将可安排课程按“依赖多→学分高→编号”排序，并尽量填满当前学期，使课程集中到前面学期。
- 排课算法基于拓扑排序思路：每个学期收集先修已完成的课程，依据策略排序、在学分上限内装入课程，完成后将课程标记为已修；若在某学期无法安排任何课程或学期耗尽仍有剩余课程，则报错提示。

### 界面
- `mainwindow.ui` 提供课程文件路径输入与读取按钮、课程文本编辑框、参数输入、策略下拉框与输出文本框。
- `mainwindow.cpp/.h` 实现界面事件与数据准备，`scheduler.cpp/.h` 实现核心算法。

### 文件格式与输入示例
- 课程文件示例（默认生成在应用目录 `courses.txt`）：每行 `课程号,课程名称,学分,先修课(以;分隔，可留空)`，支持 `#` 注释和空行。
  ```
  # 课程号,课程名称,学分,先修课(以;分隔)
  c1,程序设计基础,2,
  c2,高等数学,3,c1
  c3,数据结构,4,c1
  c4,汇编语言,3,c1
  c5,高级语言程序设计,2,c3;c4
  c6,计算机原理,4,c2;c4
  c7,编译原理,3,c3;c5
  c8,操作系统,4,c5;c6
  c9,软件工程,7,c7;c8
  c10,计算机网络,5,c6
  c11,数值计算,2,c2
  c12,数值分析,3,c1;c6;c10
  ```

### 输出
- 结果除在界面展示外，会写入应用目录下的 `schedule_output.txt`，便于提交或核对。

## 输出示例

```
学期 1（总学分 2）：c1 程序设计基础(2)
学期 2（总学分 10）：c3 数据结构(4)、c2 高等数学(3)、c4 汇编语言(3)
学期 3（总学分 8）：c6 计算机原理(4)、c5 高级语言程序设计(2)、c11 数值计算(2)
学期 4（总学分 9）：c10 计算机网络(5)、c8 操作系统(4)
学期 5（总学分 6）：c7 编译原理(3)、c12 数值分析(3)
学期 6（总学分 7）：c9 软件工程(7)
排课成功：12 门课程全部在 6 个学期内完成，总学分 42。
```

## 说明

- 程序启动时会在应用目录创建示例 `courses.txt`，可直接编辑或替换；界面“读取文件”会同步文本框内容。
- 排课算法使用拓扑排序思路：优先安排依赖多、学分高（或学分低，取决于策略）的课程，并受每学期学分上限约束；若出现环路、未知先修或学分上限太小，会抛出错误并打印提示。
